The problem

Your environment is the part you cannot carry.

The code is already portable — it has been for twenty years. What is not portable is everything around it: the toolchain versions, the twelve things you apt-got at 2am, the shell you spent an evening configuring, the one patched binary you can no longer remember installing.

Lose the laptop and you do not lose the code. You lose the machine that understood it.

The idea

Store the machine, not a description of it.

Iceberg runs an actual Alpine Linux system in your browser — a real kernel, real processes, a real package manager, a real filesystem — and stores its saved states in a private repository on your own GitHub account.

Not a container recipe that rebuilds something similar. The machine itself, as it was, down to the file.

The distinction everything rests on

A floe is what you saved. A session is what you're using.

Immutable. Named. A commit, though you never have to know that.

Session

Live, warm, and entirely yours to wreck. It exists in this tab and nowhere else.

Nothing inside a running machine is ever written to GitHub on its own. No autosave, no background commit, no quiet sync. You install four hundred packages, break the kernel, and change your mind — and the floe you thawed from is exactly as it was.

Saving

Calving is a decision, and it feels like one.

When the session is worth keeping, you calve it under a name. Iceberg reads the machine, works out which pieces of it your vault already holds, and uploads only what is genuinely new.

■ already in your vault   ■ new since the last calve

Adding a compiler to a saved machine costs the compiler — not the machine. That is why a vault holding a dozen environments is measured in hundreds of megabytes rather than dozens of gigabytes.

Lineage

Every machine remembers where it came from.

Floes form a chain. BASE is the factory machine — the clean Alpine install, always there, never editable, never removable. Everything else grows out of it.

  1. BASEthe factory machine
  2. Rust Dev+ rustup, cargo-watch, a shell you like
  3. Rust + WASM+ the wasm32 target and trunk
  4. Project X+ the dependencies, already built

To change BASE, you thaw it, change it, and calve the result under a new name. BASE stays where it is. That is the only way, and it is deliberate.

Resource discipline

The machine sleeps when you're only typing.

Emulating a processor costs a processor. Iceberg does not spend one while you are reading a file. The filesystem lives in the browser rather than inside a disk image, so the editor can open, read and write files with the machine's processor completely parked.

Running

You are doing something. Full speed.

Awash

Run loop parked after 45 seconds. Zero CPU. Wakes instantly; the machine never noticed.

Submerged

Memory written to local storage and the emulator torn down. Costs nothing. Survives a reload, or a phone taking the tab away.

Compile something, and it wakes. The interface always says which of these is true and never pretends a sleeping machine is working.

Phone

Built for the day you only have a phone.

Not a desktop terminal shrunk down. A key rail with the characters a shell actually needs, command history you can reach with a thumb, panes you swipe between, and a layout that survives the keyboard eating half the screen.

What it is not

        
The honest part.

        

          A browser emulating an x86 processor is perhaps ten to thirty times slower than the
          machine it is running on. Iceberg is a serious environment for editing, scripting,
          small builds and getting yourself out of trouble. It is not a build farm.
        

        
    
          
  • Networking is not free. The guest has no internet unless you attach a network relay you control. Without one, packages come from Iceberg's own courier, which fetches them in the browser and hands them to the machine.
    • 
          
  • GitHub has limits. 5 000 API calls an hour, and a repository that should stay under a gigabyte. Calving is designed around both, and tells you when either is close.
    • 
          
  • Storage can be evicted. Browsers reclaim space. An uncalved session is only as safe as the browser feels like being, which is why calving is one button and always visible.
    • 
          
  • Nothing here sandboxes your code from you. The machine is yours, running your software, in your tab.
